### Traffic Violation Evidence Assistant ###

## 1. 프로젝트 소개
사용자가 신호 위반 차량을 촬영할 때, 신고에 필요한 영상 요소가 제대로 확보되고 있는지 자동으로 분석하여 사용자에게 안내하는 시스템


## 2. 프로젝트를 시작한 계기
신호 위반 차량들을 동영상으로 찍어 신고하려고 했으나 교통국에서 반례를 함. 이유는 신고 증거 영상으로써 조건이 갖춰지지 않았기 때문이라고 함. 이에 사용자들이 신호 위반 차량 동영상을 찍을 때 신고 조건에 부합할 수 있도록 보조해주는 시스템


## 3. 해결하려는 문제
신호 위반 차량들을 동영상으로 찍으면서 신호등이 영상에 제대로 나오고 있는지, 차량 번호가 식별되고 있는지, 영상에 시간과 날짜가 나왔는지, 신호가 바뀌고 정지선을 넘었는지 등을 열려주기 위함.

## 16. 향후 개선
해당 서비스를 더 확장한다면 사용자들이 앱을 통해 찍은 영상들을 가지고 어떠한 지역?에서 신호 위반 차량이 많았는지 맵과 함께 알 수 있어 사용자들은 해당 구역을 지나갈 때 더욱 조심하게 된다. 
또한 국민신고 관리자에게 어떤 구역에, 어느 시간 대에 신호 위반 차량이 많았는지 시각화를 통해 볼 수 있고, 특히 신호 위반 차량이 지속적으로 많이 발생하는 구역을 파악하여 신호위반 카메라를 설치할 수 있다.
